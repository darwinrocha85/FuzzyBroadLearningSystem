# FuzzyBroadLearningSystem

Reconocimiento de emociones multimodal (audio, video, texto) con **Broad Learning
System (BLS)** + capa difusa: línea paralela a
[EmbracenetFuzzy](https://github.com/darwinrocha85/EmbracenetFuzzy) (que usa
EmbraceNet) y base de la variante unificada en `FBLS-master`. Anterior al repo
[fuzzy-embracenet](https://github.com/darwinrocha85/fuzzy-embracenet).

## Estructura
| Archivo/carpeta | Qué es |
|---|---|
| `BLS.py` / `fbls.py` | BLS clásico |
| `FUZZY-BLS.py` | BLS con capa difusa |
| `Datasets/` | Cargador IEMOCAP |
| `Utils/` | Utilidades de datos y fusión |
| `Data/` | Predicciones por modalidad (`.p`) |
